## 🌸 Projeto em destaque

### 🐾 PetCare Analytics

Projeto de **Business Intelligence** desenvolvido para simular a análise de dados de uma 
empresa do segmento veterinário.

A proposta foi construir um pequeno ambiente analítico, passando por diferentes etapas 
do ciclo dos dados: **geração da base, armazenamento, consultas, modelagem e visualização**.

**Principais tecnologias:**

`Python` • `PostgreSQL` • `Apache Superset` • `Docker`

  O projeto contém dados fictícios de tutores, animais e atendimentos veterinários e 
permite analisar indicadores e padrões relacionados à operação da empresa.

[🔗 Conheça o projeto PetCare Analytics](https://github.com/anaaraujovzz-hub/petcare-analytics)
